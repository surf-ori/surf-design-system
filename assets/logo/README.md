# Logo

- `SURF_fc.svg` (also `.png`, `.jpg`): the full-colour mark, the white wordmark in the black container with the signature curl. Use on light backgrounds.
- `SURF_diap.svg` (also `.png`, `.jpg`): the diapositive, the white container with the curl and a dark (`#1f1300`) wordmark, for imagery and dark backgrounds such as `surf-black` and `surf-orange`. Use it as it is, never inverted.
- `surf-logo.svg`: a further copy of the mark as supplied.

Never redraw or recolour the mark.
