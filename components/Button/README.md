# Button

Primary (orange), secondary (black), outline and text buttons in sm, md and lg.

The consumer provides `children` (the label, sentence case, no exclamation mark), and optionally `variant`, `size`, `disabled`, `type` and `onClick`. Use `primary` (bg-accent) for the one action a view is for, `secondary` (bg-inverse) beside it, `outline` for quiet actions and `text` for a link-like action with a trailing →. Radii come from the size (8, 10, 12px). Hover darkens, disabled sits at 50% opacity. White label text on `surf-orange` reads 3.08:1, below 4.5:1: keep labels bold and the md or lg size.
